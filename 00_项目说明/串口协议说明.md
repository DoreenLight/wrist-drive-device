# 串口协议说明

本文档描述上位机（`protocolworker.cpp`）与下位机 MCU 之间的自定义二进制串口协议。
所有 ID 定义集中在 `01_上位机程序/floatiddefs.h`。

---

## 1. 帧格式

```text
┌────────┬────────┬──────┬──────┬──────────────┬──────┬──────┐
│ SYNC_H │ SYNC_L │ LEN  │ CMD  │   PAYLOAD    │ SUM  │ END  │
│  0x6C  │  0x67  │ 1B   │ 1B   │  LEN 字节     │ 1B   │ 0xED │
└────────┴────────┴──────┴──────┴──────────────┴──────┴──────┘
```

| 字段 | 长度 | 说明 |
|---|---|---|
| `SYNC_H` | 1B | 帧头高字节，固定 `0x6C` |
| `SYNC_L` | 1B | 帧头低字节，固定 `0x67` |
| `LEN` | 1B | 载荷长度，最大 `250`（`FRAME_MAX_LEN`） |
| `CMD` | 1B | 命令码 |
| `PAYLOAD` | `LEN` 字节 | 命令载荷，可为空（`LEN=0`） |
| `SUM` | 1B | 校验和 |
| `END` | 1B | 帧尾，固定 `0xED` |

整帧长度 = `LEN + 6`，最短帧为 6 字节（`LEN=0`）。

### 校验和计算

```text
SUM = (LEN + CMD + Σ payload[i]) & 0xFF
```

即：长度、命令码与所有载荷字节的算术和，取低 8 位（模 256）。

## 2. 命令码

### 上位机 → MCU

| 命令码 | 名称 | 载荷 | 说明 |
|---|---|---|---|
| `0x01` | `IO_WRITE` | `[io_id][value]` | 写 IO / 控制量（启停、模式切换等） |
| `0x02` | `FLOAT_WRITE` | `[float_id][float32]` | 写入单个浮点参数 |
| `0x03` | `BATCH_WRITE` | `[cnt][(float_id,float32)]*` | 批量写入多个浮点参数 |
| `0x84` | `PING` | 无（`LEN=0`） | 通信测试 |
| `0x85` | `FLASH_SAVE` | 无（`LEN=0`） | 请求下位机把参数保存到 Flash |

### MCU → 上位机

| 命令码 | 名称 | 载荷 | 说明 |
|---|---|---|---|
| `0x81` | `TELEMETRY` | `[cnt][(float_id,float32)]*` | 遥测数据上传 |
| `0x82` | `IO_REPORT` | `[io_id][value]` | IO 状态上报 |
| `0x83` | `ACK` | `[ack_cmd]` | 命令应答，回带被应答的命令码 |

---

## 3. 载荷编码

### 浮点数值

所有浮点数均为 **IEEE 754 单精度，小端序（little-endian）**，占 4 字节。

例如 `12.5f` → `00 00 48 41`。

### `IO_WRITE`（0x01）

```text
偏移 0 : io_id   (1B)
偏移 1 : value   (1B)
```

### `FLOAT_WRITE`（0x02）

```text
偏移 0 : float_id (1B)
偏移 1 : value    (4B, float32 小端)
```

### `BATCH_WRITE`（0x03）

```text
偏移 0 : count (1B)
随后   : count 组 ( float_id(1B) + value(4B小端) )
```

### `TELEMETRY`（0x81）

```text
偏移 0 : count (1B)
随后   : count 组 ( float_id(1B) + value(4B小端) )
```

### `IO_REPORT`（0x82）

```text
偏移 0 : io_id   (1B)
偏移 1 : value   (1B)
```

### `ACK`（0x83）

```text
偏移 0 : ack_cmd (1B)   ← 被应答的命令码
```

## 4. 帧示例

### PING

```text
LEN=0, CMD=0x84
SUM = (0 + 0x84) & 0xFF = 0x84

发送: 6C 67 00 84 84 ED
```

### `IO_WRITE`：M1 启动（io_id=0x01, value=1）

```text
LEN=2, CMD=0x01, PAYLOAD = 01 01
SUM = (2 + 1 + 1 + 1) & 0xFF = 0x05

发送: 6C 67 02 01 01 01 05 ED
```

### `FLOAT_WRITE`：写 M1 最大速度 = 30.0（float_id=0x07）

```text
30.0f = 0x41F00000 → 小端 00 00 F0 41
LEN=5, CMD=0x02, PAYLOAD = 07 00 00 F0 41
SUM = (5 + 2 + 0x07 + 0x00 + 0x00 + 0xF0 + 0x41) & 0xFF = 0x3F

发送: 6C 67 05 02 07 00 00 F0 41 3F ED
```

## 5. 接收解析与容错

上位机的解析器（`ProtocolWorker::parseFrame`）按以下顺序处理接收缓冲区：

1. 搜索 `SYNC_H`（`0x6C`），跳过前面的垃圾字节；
2. 校验下一字节是否为 `SYNC_L`（`0x67`），否则只跳过 1 字节继续搜索；
3. 读取 `LEN`，若 `> 250` 则判定为假帧头，跳过 1 字节；
4. 若缓冲区数据不足整帧长度，则等待更多数据；
5. 校验帧尾必须为 `END`（`0xED`），否则跳过 1 字节重新同步；
6. 校验和比对：
   - **校验通过** → 计数 +1，进入 `processFrame()` 分发；
   - **校验失败** → 错误计数 +1，并把原始帧记录到错误日志。

### 错误帧日志

校验失败的帧会写入 **exe 所在目录** 的 `error_frames.txt`，格式为：

```text
[chk_fail] rxSum=0xXX calcSum=0xXX len=N cmd=0xXX raw=6C 67 .. ED
```

缓冲区每累积 50 条记录或程序退出时刷盘。

### 统计信息

界面会显示两个统计量：

- **总帧数**（`m_totalFrames`）：成功定位并读取到的帧数；
- **校验错误数**（`m_checksumErrors`）。

正常情况下校验错误数应保持不增长或极低速增长；若持续快速增长，说明
波特率不匹配、接线干扰或下位机固件协议不一致。

## 6. IO ID 定义

| ID | 名称 | 取值说明 |
|---|---|---|
| `0x01` | M1 启停 | `1`=启动，`2`=停止 |
| `0x02` | M1 控制模式 | 见 M1 模式表 |
| `0x03` | M2 启停（使能/停止） | `1`=使能，`2`=停止 |
| `0x04` | M2 RS00 运行模式 | 见 M2 模式表 |
| `0x05` | M2 机械零点 | — |
| `0x06` | M2 清除故障 | — |
| `0x07` | M2 轨迹模式 | `0`=位置，`1`=速度 |
| `0x08` | M1 康复启停 | `1`=启动，`2`=停止 |
| `0x09` | M2 康复启停 | `1`=启动，`2`=停止 |
| `0x0A` | 系统启停（TIM2 控制循环） | `1`=启动，`2`=停止 |
| `0x0B` | M1 主动康复启停 | `1`=启动，`2`=停止 |
| `0x0C` | 力传感器清零 | — |
| `0x0D` | M2 主动康复启停 | `1`=启动，`2`=停止 |
| `0x0E` | M2 主动康复模式 | `1`=Fy，`2`=Fz |

### 通用取值

| 常量 | 值 |
|---|---|
| `IO_VAL_START` / `IO_VAL_ENABLE` | `1` |
| `IO_VAL_STOP` | `2` |

### M1 控制模式（IO_ID = 0x02）

| 值 | 模式 |
|---|---|
| `0` | 位置 |
| `1` | 速度 |
| `3` | PWM 测试 |

### M2 RS00 运行模式（IO_ID = 0x04）

| 值 | 模式 |
|---|---|
| `1` | 运控 |
| `2` | 位置 |
| `3` | 速度 |
| `5` | CSP |

### M2 轨迹模式（IO_ID = 0x07）

| 值 | 模式 |
|---|---|
| `0` | 位置 |
| `1` | 速度 |

## 8. 串口参数

上位机默认支持配置：波特率、数据位、校验位、停止位、流控。

**具体使用的波特率必须与下位机固件一致**；代码中没有硬编码默认值，
需在界面中手动选择。若通信异常，优先排查波特率与接线（TX/RX 是否交叉、是否共地）。
