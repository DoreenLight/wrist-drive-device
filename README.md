# 腕部驱动设备 — 上位机

腕关节康复设备（腕部驱动设备）的 PC 端串口控制台，基于 **Qt 6 / C++** 开发。
用于通过串口连接下位机 MCU，控制 M1/M2 两个电机与康复流程，接收并显示
电机、IMU、六维力传感器遥测数据，并把遥测数据记录为 CSV 文件。

## 快速开始

### 直接运行（无需编译）

双击：

```text
build\Desktop_Qt_6_8_2_MinGW_64_bit_Release\Uart_controller.exe
```

窗口标题为 **“腕关节康复设备串口控制台”**。
Qt 与 MinGW 运行库已部署到该 exe 同目录，可直接运行，无需额外配置环境变量。

### 重新编译

在 PowerShell 中执行：

```powershell
.\03_构建与辅助工具\build.ps1
```

脚本会自动配置 CMake、编译并把运行库部署到 exe 同目录。

### 用 Qt Creator 打开

打开 `01_上位机程序\CMakeLists.txt`，选择 **Desktop Qt 6.8.2 MinGW 64-bit** 套件。

> **重要**：必须使用 **Release** 配置。本机 Qt 只安装了 Release 运行库，
> 没有 Debug 版 DLL（`Qt6Cored.dll` 等），Debug 配置编译出的程序无法运行。

## 已知限制与注意事项

### 1. 项目路径含中文，必须通过 ASCII 联接构建

Qt 的 `moc.exe` 无法处理含中文的路径，会报：

```text
moc: Cannot create C:/Users/Lenovo/Desktop/鑵曢儴椹卞姩璁惧/... Error: No such file or directory
```

因此 `03_构建与辅助工具\build.ps1` 会自动创建一个 ASCII 路径的目录联接（junction）：

```text
C:\Users\Lenovo\uart_wrist  →  C:\Users\Lenovo\Desktop\腕部驱动设备
```

通过该联接路径构建即可正常工作。**该联接不复制、不移动任何源码。**
直接双击运行 exe 不受此限制影响。

### 2. 只能使用 Release 构建

本机 Qt 未安装 Debug 运行库，Debug 构建产物无法启动。

### 3. 数据文件写入位置

CSV 记录与 `error_frames.txt` 写入 **exe 所在目录**（即程序运行目录），
而不是 `02_采集数据\telemetry\`。采集完数据后需要手动归档到 `02_采集数据\telemetry\`。

### 4. 记录功能只在停止时落盘

代码中遥测数据先缓存到内存（`m_recordBuffer`），**点击“停止记录”时才写入 CSV**。
请勿在记录过程中直接结束进程，否则数据会丢失。

## 轨迹跟踪视图（✅ 已实现，2026-10-16）

> 需求与 5 项决策见 `00_项目说明/需求_轨迹跟踪视图改造.md`；
> **实现细节、与规格的差异、验证证据与验证局限见该文档 §10「实现记录」**。

康复治疗页的两张曲线（Motor1：`0x01`/`0x02`/`0x0B`；Motor2：`0x11`/`0x12`/`0x1D`）
已从「实时滚动曲线」改为「固定参考轨迹 + 时间游标 + 扫描式历史轨迹」的实验展示模式：

- 绿色参考轨迹由**上位机本地生成**（不再依赖下位机 `0x0B`），N 个周期，N 可调、默认 5；
- **图例固定显示三项：参考轨迹（绿）/ 轨迹输入（蓝）/ 反馈角度（橙）**，在开始前、运行中、结束后、重新开始后均完整；
- **已收到的历史数据按时间顺序持续连成曲线**，随游标从左向右逐步绘制（扫描式），游标左侧是已扫过的实际轨迹、右侧是尚未到达的绿色参考；
- X 轴固定为整个实验时长 `T = N × (2×停顿 + 2×(极限角2−极限角1)/T波速度)`（默认参数下 5 周期 = 40 s）；
- 一条竖直线随时间从左向右移动，代表当前实验时间；
- 游标上 🔵 目标角度（**蓝色方形**）、🟠 实测角度（**橙色圆形**）各一个点；
- 图表下方读数：`当前时间 / 参考角度 / 目标角度 / 实测角度 / 跟踪误差`；
- 结束后停在最右、不自动循环；点「重新开始」进入下一轮，参考轨迹逐点相同；
- **「开始实验」不下发任何指令**（与电机启停完全解耦）。

参考轨迹参数取自各电机「主动」选项卡的 `T波速度 / 极限角1 / 极限角2 / 停顿时间` 输入框；
**参数不会因为点「开始实验」而下发到设备**，是否下发仍由 `▶ 启动` 按钮决定。

康复页套在 `QScrollArea` 里：窗口较小（尤其高 DPI）时会出现滚动条，而**不会把底部内容裁切**。

**尚未处理的遗留项**

- **遥测帧 100% 校验失败的设备侧 bug**（已定位到损坏区间与地址特征，见需求文档 §6.1），
  属下位机固件问题，与上述界面改造**分开处理**；
- 为此已在渲染前加了「数值合理性过滤」（非有限值或 `|angle| > |极限角|×1.5` 丢弃并计数），
  否则 Motor2 的实测点会被 `0x12` 的损坏值甩到图外。

## 安全提示

本程序可向设备下发电机启停、模式切换、康复动作、Flash 保存等命令。
连接真实硬件前请确保：

- 设备处于安全状态，急停/断电方式可用；
- 空载测试通过后再接触人体；
- 谨慎使用机械零点、清除故障、力传感器清零、Flash 保存等持久化操作。
